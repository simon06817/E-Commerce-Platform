# AI Agent

电商平台的智能助手服务，基于 FastAPI、LangChain/LangGraph 和 Ollama，通过受控工具调用 Java 后端，而不是直接访问业务数据库。

## 能力

- 根据当前登录用户角色开放不同工具。
- 查询商品、分类、订单、购物车、退款、通知、评价和卖家统计。
- FAQ、政策和商品描述使用 Chroma 做语义检索。
- 价格、库存、订单和账号数据实时调用 Java API。
- 可选 Tavily 外部检索，只作为不可信参考资料。
- 写操作先提出建议，用户确认后再执行。
- `/chat/stream` 输出 NDJSON 事件，模型回答按实际分块流式返回。
- SQLite 保存最近对话，最后一条消息后继续保留 24 小时，并在后台清理过期数据。

## 设计边界

Java 后端始终是权限、事务和数据归属的最终校验方。Agent 会携带用户 JWT 调用后端接口，不接触数据库凭据，也不允许模型根据搜索结果直接执行写操作。

RAG 只保存语义知识，避免把实时库存、价格和订单状态放进向量库。确定性业务问题优先由经过校验的后端数据直接回答，开放问题再交给模型组织自然语言。

## 技术栈

- FastAPI、Pydantic
- LangChain、LangGraph
- Ollama、Chroma
- SQLite
- Python unittest

## 测试

测试覆盖身份传递、工具权限、意图路由、两阶段确认、商品查询、推荐分类、SQLite 滑动 TTL、历史恢复和流式分块。当前共 `50` 个测试通过。
